# Instagram Login Clone

Recriação de uma interface de autenticação inspirada no Instagram, desenvolvida para praticar formulários, duas colunas e responsividade.

<a href="./docs/media/preview.png">
  <img src="./docs/media/preview.png" alt="Pré-visualização do Instagram Login Clone" width="900" />
</a>

## Funcionalidades

- Página de início de sessão.
- Página de criação de conta.
- Layout responsivo com chamadas para as lojas de aplicações.

## O que aprofundei

- Estruturação de formulários de autenticação com campos, ações e navegação entre páginas.
- Criação de um layout em duas colunas e gestão de imagens e outros assets.
- Aplicação de media queries para adaptar a interface a dispositivos móveis.

## Como executar

Abra `index.html` no navegador. Para aceder diretamente ao registo, abra `signup.html`.

## Nota

É uma interface de estudo: os formulários não enviam credenciais nem ligam a qualquer serviço.
