# Lista de Tarefas

Aplicação web simples para registar e remover tarefas. Os dados permanecem guardados no navegador através de `localStorage`.

![Pré-visualização da Lista de Tarefas](./docs/media/preview.png)

## Vídeo de demonstração

[▶ Ver demonstração curta](./docs/media/demo.mp4)

## Funcionalidades

- Adição de tarefas com validação de campo vazio.
- Remoção de tarefas individuais.
- Persistência da lista entre sessões do navegador com `localStorage`.

## Tecnologias

`HTML5` · `CSS3` · `JavaScript`

## Como executar

Abra `index.html` no navegador. Não requer dependências nem servidor local.
